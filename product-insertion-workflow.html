Product insertion workflow

A simple way to run a product-insertion project in ChatGPT without losing track of the source images, approvals, or final exports.

The workflow

1

Upload both ZIPs to ChatGPT

Upload the starter-image ZIP and the product ZIP in the same chat. Then tell ChatGPT which ZIP contains the starting frames and which one contains the product references.

2

Make it confirm it can access the ZIPs

Before generating anything, explicitly ask ChatGPT to confirm that it can open both ZIPs and use the files inside them. Do this again before every new batch. This matters because generations can drift or glitch when the files are no longer available to the chat.

3

Generate five at a time

Tell ChatGPT to use five unused starting frames from the starter ZIP and make five separate product insertions. Review the batch in its displayed order.

4

Approve, reject, or redo by number

Reply with simple decisions such as “keep 1, 3, and 5,” “redo 2,” or “eliminate 4.” Ask ChatGPT to lock in each decision and keep track of the source image and latest approved version before moving to the next five.

5

Repeat until every starting frame is reviewed

Continue in batches of five. Each time, have ChatGPT confirm ZIP access and pull the next unused images from the starter folder.

6

Export the approved images

When all decisions are final, ask ChatGPT to export only the approved images, use one final version per source frame, and include a ZIP plus an export manifest.

The important habit: before every batch, ask ChatGPT to confirm it still has access to both ZIPs. It should work from those files, not from memory or a previous generation.
